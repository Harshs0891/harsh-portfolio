# Harsh Kumar Singh — Software Engineering Portfolio

Personal engineering portfolio of **Harsh Kumar Singh** (**Software Engineer @ PayPal** · **IIIT Lucknow '26**)[cite: 1]. Architected with **Next.js (App Router)**, **TypeScript**, **Tailwind CSS v4**, and **Motion** to showcase high-throughput distributed data systems, production query/pipeline optimizations, and full-stack AI product engineering[cite: 1].

---

## Architectural Highlights

- **Concept A+ (Architectural Precision)**: Dark-mode-first Swiss structural grid (`#090A0F` obsidian canvas, exposed `1px` hairlines, and tabular monospace telemetry numerals).
- **Contextualized Impact Ledger**: Displays verified production metrics from PayPal (`99.88%` BigQuery bytes reduction, `28–30M` transaction Spark/Scala migration, `~35%` query batching slot savings)[cite: 1] with strict workload isolation and animated Before/After comparison bars.
- **Interactive System Schematics**: Custom 3-tier interactive architecture flow for **EduGenius** (`Next.js Client Workspace` ↔ `Gemini API Orchestration` ↔ `Drizzle ORM / PostgreSQL & PDF Compiler`)[cite: 1] plus dedicated `/work/[slug]` case study routes.
- **Single Source of Truth Data Layer**: All portfolio copy, metrics, experience timelines, and skills taxonomy are strictly typed in `src/types/portfolio.ts` and centralized in `src/data/portfolio-data.ts`.
- **Accessibility & Performance**: Built with React Server Components by default, `prefers-reduced-motion` support, semantic landmarks, and zero unnecessary client-side state bloat.
